# ITTHAD CRM — استوديو الاتحاد

نظام أولي لإدارة المحتوى الإعلامي لقناة الاتحاد السكندري، بواجهة عربية RTL وتصميم متجاوب.

## تشغيل المشروع

```bash
npm install
npm run dev
```

لبناء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## الموجود حاليًا

- لوحة تحكم ومؤشرات لحالة المهام
- إدارة المحتوى: إضافة مهمة، بحث، فلترة، تغيير الحالة، حذف
- مركز المباريات: حفظ بيانات المباراة وإنشاء مهمة لتصميم تقديمها
- أقسام منفصلة للتصميم والفيديو والريلز
- قائمة لمواعيد النشر
- إحصائيات محلية
- تصدير واستيراد بيانات بصيغة JSON

## مهم قبل الاستخدام الفعلي

**هذه نسخة تجريبية Frontend-only**. المهام والمباريات مخزنة في localStorage على الجهاز الحالي فقط، ولا تنتقل بين الأجهزة تلقائيًا. لا يوجد نظام حسابات أو صلاحيات أو Firebase أو نشر تلقائي للسوشيال ميديا بعد. بيانات العرض الأولى مجرد أمثلة.

لا ترفع بيانات خاصة أو مفاتيح سرية إلى هذا المستودع، ولا تعتبر واجهة الموقع بديلًا عن نظام حماية للخادم. لاستخدامها مع فريق عمل أو بيانات حساسة، يلزم بناء مصادقة آمنة وقواعد Firestore Security Rules وتخزين سحابي وضبط الصلاحيات قبل النشر.

## الخطوات التالية المقترحة

1. Firebase Authentication + Firestore + Storage مع قواعد أمن صارمة واختبارات.
2. الصلاحيات (مدير / محرر / مصمم / مراجع).
3. إدارة الأصول والصور والقوالب.
4. جدولة المحتوى وربط الحسابات الاجتماعية بالواجهات الرسمية.
5. سجل المراجعات وتاريخ التعديلات.

## Deployment

يمكن ربط المستودع بـ Vercel أو Netlify. إعدادات Vite المعتادة: build command `npm run build`، ومجلد النشر `dist`.
